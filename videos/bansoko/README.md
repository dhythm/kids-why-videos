# ばんそうこうは なんで はるの？

「きずが なおったのに、ばんそうこうを はりたい！」という こども（保育園児・3〜6さいくらい）に、ばんそうこうの やくわりと、はる とき・はらない ときを つたえる、約2分30秒のモーショングラフィックス動画です。
文字はひらがなを少しだけにして、絵と動きで伝えます。

伝えたいことは、次の5つです。

- ひふは からだを まもる かべ。けがを すると あなが あいて、ばいきんが はいりやすく なる
- きずを なおすのは、ばんそうこう ではなく、じぶんの からだ（からだの なかの「なおしやさん」）
- ばんそうこうは「きずの やね」。ばいきん・よごれ・こすれから まもり、きずを かわかさない
- いたいのは からだの「おしらせ ベル」。ばんそうこうは いたみを けす くすり ではない（ふくや てが さわるのを ふせぐ だけ）。なおって くると ベルは しずかに なる
- あたらしい ひふが できたら、ばんそうこうは おしまい。けがが ないのに いたい ときは、ひやす・なでなで・ぎゅー

こどもを せめる 言いかた（「わがまま」「だめ」）は つかわず、「なおったら おしまい」「かわりに なでなで」と、できる ことを しめす つくりに しています。

## シーン

1. はじまり — ころんで ひざから ち。ばんそうこうを ぺたっ。なんの ために はるの？
2. ひふは かべ — ひふは じょうぶな かべ。けがで あなが あくと、ばいきんが はいろうと する
3. なおしやさん — からだの なかの なおしやさんが、ちを とめて、あたらしい ひふで あなを ふさぐ。なおすのは からだ
4. きずの やね — ばんそうこうは やね。ばいきんや よごれを はねかえし、きずを かわかさない
5. いたいのは？ — いたみは おしらせ ベル。ばんそうこうは くすり じゃない。さわるのを ふせぐ だけ。なおると ベルは しずか
6. はる とき — ちが でた・じゅくじゅく の とき。みずで あらって ぺたっ。ぬれたり よごれたら とりかえる
7. なおったら — あたらしい ひふが からだの ばんそうこう。ずっと はると むれて ふやける・かゆくなる
8. いたい ときは — けがが ないのに いたい ときは、ひやす・なでなで・ぎゅー
9. ふりかえり — やね → からだが なおす → なおったら おしまい。またね！

- 2D: SVG + React（Remotion）。こども・ラベル・ことばの 部品は `natto` から 流用
- きずの ふさがりかた・いろ・いたみの つよさは `src/lib/wound.ts`（テスト つき）
- BGM: Python（numpy）で合成
- ナレーション: ElevenLabs `eleven_v4`（声: Sameno）。せりふごとに べつべつに 生成し、あたまと おしりの むおんを きって みじかく フェード
- サムネイル: 専用イラストの `thumbnail.jpg`（1280×720、YouTube アップロード用）。元画像は `thumbnail.png`、生成プロンプトは `thumbnail_prompt.txt`。Remotion の `Thumbnail` も同じ画像（`public/thumbnail.jpg`）を表示します

## 内容の根拠（おとな向け）

| 動画での 言いかた | 根拠・注意 |
| --- | --- |
| ひふは からだを まもる かべ | 皮膚（とくに 表皮の 角層）は、微生物や 異物の 侵入と 水分の 蒸発を ふせぐ バリア。きずは その バリアの 切れ目 |
| なおすのは きみの からだ（なおしやさん） | 創傷治癒は、止血（血小板・フィブリン）→ 炎症（白血球が 細菌や こわれた 組織を かたづける）→ 増殖（線維芽細胞・表皮細胞が 組織を つくり、表皮が はしから のびて おおう）→ 成熟、と すすむ。ふつうの ばんそうこうに「なおす 成分」は 入っていない。「なおしやさん」は これらの 細胞を まとめた たとえ |
| ばんそうこうは きずの やね。ばいきんや よごれを ふせぐ | 被覆の おもな 役割は、外からの 汚染・摩擦からの 保護と、しみだした 血液・滲出液の 吸収。ただし 絆創膏は 無菌の 密閉では なく、感染を かならず ふせげる わけではない（だから まず 洗う） |
| きずを かわかさない ほうが なおしやさんが はたらきやすい | Winter（1962）は ブタの 浅い きずで、フィルムで おおって 湿った ままに した きずの ほうが、乾かして かさぶたに した きずより 表皮化が 速いと 報告。Hinman & Maibach（1963）は ヒトで 同様の 傾向を 報告。数字（「2倍」など）は 文献に よって 幅が あるので、動画では「はたらきやすい」と 言うに とどめた |
| いたいのは おしらせ ベル | 痛みは 組織の 損傷（または その おそれ）を 知らせる 警告信号（侵害受容）。きずの 周りでは 炎症物質で 神経が 敏感に なり、治るに つれて おさまる |
| ばんそうこうは いたいのを けす くすり じゃない。さわるのを ふせぐ だけ | ふつうの 絆創膏に 鎮痛成分は ない。おおう ことで、衣類や 手との 接触・摩擦、乾燥や 空気の 刺激が へり、その ぶんの 痛みは やわらぐ（ハイドロコロイドなど 湿潤環境を たもつ 被覆材は 痛みが 少ないと される）。つまり「痛みの もとを 消す」のでは なく「刺激を へらす」。なお、はって もらった 安心感で 痛みが 軽く 感じられる ことは ありうる（気持ちの 効果）が、動画では ふれていない |
| ちが でたり じゅくじゅく の とき に はる／あらって ぺたっ | 浅い きずは、まず 水道水で よごれを 洗いながす。出血は 清潔な ガーゼなどで おさえて 止める。軽い きずに 消毒は 基本的に 不要と されている。動画では「おさえて 止める」は はぶいた |
| ぬれたり よごれたら とりかえる | ぬれた・汚れた 被覆は 細菌が ふえやすく、ひふも ふやける ため 交換する |
| あたらしい ひふが できたら もう はらない | 表皮が きずを おおい（上皮化）、滲出液が なくなれば、バリアは 戻っており 被覆は 不要。あたらしい ひふは しばらく ピンク色で うすい ので、こすれやすい 場所や 日焼けには 気を つける |
| ずっと はると むれて ふやける・かゆくなる | 健康な ひふを 長く おおうと、汗や 水分が こもって 白く ふやける（浸軟）。粘着剤に よる かぶれ（接触皮膚炎）や、はがす ときに 角層が はがれる ことも ある（医療用粘着剤関連皮膚損傷：MARSI）。「ひふが 息を できない」は 正確では ない（ひふは 空気から 呼吸して いない）ので、「むれる」と 言った |
| なでなで して もらうと いたいのを ちいさく かんじる | 触る・さする 刺激が 痛みの 伝わりを 弱める（ゲートコントロール説：Melzack & Wall 1965）。触刺激で 痛みの 感じかたが 下がる ことは 成人の 実験で くりかえし 示されているが、ヒトでの くわしい しくみは 議論が ある。こどもへの 親の タッチ そのものを 調べた 研究は ここでは 確認していない |
| ぶつけた ところは ひやす | 打撲は 冷やすと 痛みと はれが やわらぐ。氷は タオルで くるみ、長く 当てすぎない |

### 依頼時の 理解に ついて（確認した こと）

- 「ばんそうこうを はっても 痛みは とれない」→ **おおむね 正しい**。鎮痛成分は なく、効くのは「さわる・こすれる・乾く」刺激を へらす 部分だけ。動画でも その ように 言っている。
- 補足として、ばんそうこうは「なおす もの」でも ない（なおすのは からだ）。この 点を 動画の 中心に した。
- 「血も 出ていない、化膿も していない なら 不要」→ 正しい。上皮化して 乾いていれば 不要で、はりつづけると ふやけ・かぶれの もとに なる。

### おうちでの 注意

- 小さい こどもは、はがれた ばんそうこうを 口に 入れる ことが あり、のどに つまる おそれが あります（とくに 指や 手に はった とき）。はがれた ものは すぐ すてて ください。
- 深い きず、血が 止まらない きず、よごれが とれない きず、動物に かまれた きず、赤く はれて 熱を もつ・うみが 出る ときは、受診して ください。
- 「はりたい」気持ちは、安心したい・かまって ほしい 気持ちの あらわれの ことも 多いです。動画の さいごの「なでなで・ぎゅー」や、ぬいぐるみ・紙に はる シール あそびを かわりに すると おさまりやすい、と いうのは 作者の 提案で、文献で 確認した ものでは ありません。

## 必要なもの

- Node.js 22 以上
- Python 3 + numpy
- ffmpeg

## 使いかた

```bash
npm i
npm run bgm      # BGM を生成（プレビューの前に 1 回）
npm run dev      # Remotion Studio でプレビュー
npm run render   # BGM を生成して out/bansoko.mp4 に書き出し
npm test         # タイミング計算・きずの なおりかたの テスト
npx remotion still src/index.ts Thumbnail out/thumbnail.png   # 専用サムネイルの書き出し
```

python3 に numpy が ないときは `uv run --no-project --with numpy python scripts/make_bgm.py public/bgm.wav` でも作れます。

## ナレーション

台本 `src/narration.json` に、せりふごとの「シーン番号（0はじまり）」と「シーン内で話しはじめるフレーム（at）」が入っています。
シーンの ながさは `src/lib/durations.ts` に まとめてあります。
音声 `public/voiceover/*.mp3` はリポジトリに含めています（TTS は作るたびに少し変わるため）。

- 台本を変えたら `.env`（この フォルダ か リポジトリの ルート）に `ELEVENLABS_API_KEY=...` を書いて `npm run voiceover`。変わったセリフだけを作り直し、`src/voiceover-manifest.json` に長さを記録します。
- 全せりふを whisper（mlx-whisper large-v3-turbo）で 聞きとり、台本どおりに 読まれていることを たしかめています。
- せりふが まえや つぎの せりふに かさなると、プレビュー・書き出しが エラーで とまります。シーンの きりかえに かかる せりふは `npm test` で みつかります。
- 話しているあいだは BGM が自動で小さくなります。
