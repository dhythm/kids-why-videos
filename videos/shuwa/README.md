# しゅわって なあに？

こども（4〜6さいくらい）向けに「手話は なんの ために あって、どんな ことばなのか」を紹介する、約2分30秒のモーショングラフィックス動画です。
ほいくえんで 手話を ならって たのしく つかっている こが、「耳が 聞こえない人と はなす ための ことば」だと わかるように つくりました。

1. はじまり — ほいくえんで 手話を ならった！「ありがとう」。でも、なんの ため？
2. みみ — 耳で 音を きいている。でも、聞こえない人や すこししか 聞こえない人も いる
3. とどかない — こえで「おーい！」と よんでも、とどかない。どうしたら はなせる？
4. めで みる ことば — 目で 見える ことばなら つたわる。手と かおで はなす ことば＝手話
5. ほんものの ことば — 聞こえない人たちが みんなで つくって そだてた。日本語・英語と おなじ ことば
6. かおも だいじ — 「うれしい」は にっこり わらって。かおも ことばの なかま
7. いろんな ところ — おうち・テレビの ニュース・がっこう
8. 音が なくても — うるさい ところや まどの むこうにも とどく
9. はなす コツ — かたを とんとん、手を ふる。かおを 見て、くちを はっきり、みぶりや 字も
10. やってみよう — 「こんにちは」「ありがとう」
11. ふりかえり — 聞こえない人も いる → 手と かおの ことば → なかよく なれる。またね

## 手話の うごき（日本手話の 基本的な 形を もとに 簡略化）

- ありがとう: よこにした 手の こうに、たてにした 手を のせて 上げる（おじぎ しながら）
- こんにちは: 人さし指と 中指を おでこに あてる（昼）→ 両手の 人さし指を むかいあわせて おじぎ させる（あいさつ）
- うれしい: 両手を むねの まえで こうごに 上下させる
- 手話: 両手の 人さし指を むかいあわせて こうごに まわす

絵の 都合で 形を かんたんに しています。正しい 形は 保育園の 先生や 手話の 教材で たしかめてください。

- 2D: SVG + React（Remotion）。うでは 2本の ぼうの IK（`src/lib/arm.ts`）で、手の 位置から ひじを 決めています
- 手話の うごき: `src/lib/signs.ts`（フレームごとの 手の 位置・形）
- BGM: Python（numpy）で合成
- ナレーション: ElevenLabs `eleven_v4`（声: Sameno）

## 使いかた

```bash
npm i
npm run bgm      # BGM を生成（プレビューの前に 1 回）
npm run dev      # Remotion Studio でプレビュー
npm run render   # BGM を生成して out/shuwa.mp4 に書き出し
npm test         # タイミング計算・うでの IK・手話の うごきの テスト
```

## ナレーション

台本 `src/narration.json` に、せりふごとの「シーン番号（0はじまり）」と「シーン内で話しはじめるフレーム（at）」が入っています。
音声 `public/voiceover/*.mp3` はリポジトリに含めています。

- 台本を変えたら `.env`（この フォルダ か リポジトリの ルート）に `ELEVENLABS_API_KEY=...` を書いて `npm run voiceover`。
- せりふが まえや つぎの せりふに かさなると、プレビュー・書き出しが エラーで とまります。

## 構成

```
src/
  ShuwaVideo.tsx        シーンをつなぐ本体 + ナレーション/BGM
  scenes/               シーン（S01〜S11）
  components/           人（Person.tsx）・登場人物（cast.ts）・耳・テレビ・まど など（Things.tsx）・文字
  lib/                  アニメーション・タイミング計算・うでの IK（arm.ts）・手話の うごき（signs.ts）
scripts/
  make_bgm.py           BGM 合成
  generate-voiceover.ts ナレーション生成
  stills.mjs            確認用の静止画書き出し
```

Remotion の利用には条件によって会社ライセンスが必要です（[ライセンス](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md)）。
