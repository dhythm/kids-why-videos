# くものすって どうやって つくるの？

こども（4〜6さいくらい）向けに「くものすは どうやって つくるのか・なんのために つくるのか」を紹介する、約3分のモーショングラフィックス動画です。
文字はひらがなを少しだけにして、絵と動きで伝えます。

1. はじまり — 木の あいだに キラキラの あみ。「どうやって？ なんのため？」
2. くもの いと — おしりの さきから 出る。なかでは とろとろ、そとに 出ると ほそくて じょうぶな いと
3. はしを かける — いとを かぜに のせて ふわーっ → むこうの えだに ぴたっ
4. わく と たていと — まわりの わく → じてんしゃの タイヤ みたいに まんなかから そとへ
5. よこいと — そとがわから まんなかへ ぐるぐる。1じかん くらいで できあがり
6. ねばねば — よこいとには ねばねばの つぶつぶ、たていとは つるつる。くもは たていとを あるく
7. むしを つかまえる — むしが くっつくと ぶるぶる ゆれて、くもは あしで きづく
8. たべる — むしを たべて げんきに。ふるい すを たべて あたらしい いとに する くもも いる
9. みつけたら — あさつゆで キラキラ。こわさないで そーっと 見てね
10. ふりかえり — はしを かける → たていと・よこいと → むしの わな。またね

- 2D: SVG + React（Remotion）
- くものすの かたち（わく・たていと・よこいと）は `src/lib/web.ts` で計算
- BGM: Python（numpy）で合成
- ナレーション: ElevenLabs `eleven_v4`（声: Sameno）。せりふごとに べつべつに 生成し、あたまと おしりの むおんを きって みじかく フェード

※ わくや よこいとの はりかたは、ニワオニグモ・ジョロウグモ など「まるい あみ」を はる くもを もとに、こども向けに かんたんに しています（あしばの いと などは はぶいています）。

## 必要なもの

- Node.js 22 以上
- Python 3 + numpy
- ffmpeg

## 使いかた

```bash
npm i
npm run bgm      # BGM を生成（プレビューの前に 1 回）
npm run dev      # Remotion Studio でプレビュー
npm run render   # BGM を生成して out/kumonosu.mp4 に書き出し
npm test         # タイミング計算・くものすの かたちの テスト
```

## ナレーション

台本 `src/narration.json` に、せりふごとの「シーン番号（0はじまり）」と「シーン内で話しはじめるフレーム（at）」が入っています。
音声 `public/voiceover/*.mp3` はリポジトリに含めています（TTS は作るたびに少し変わるため）。

- 台本を変えたら `.env`（この フォルダ か リポジトリの ルート）に `ELEVENLABS_API_KEY=...` を書いて `npm run voiceover`。変わったセリフだけを作り直し、`src/voiceover-manifest.json` に長さを記録します。
- 自分で録音する場合: `public/voiceover/<id>.mp3` に置き、`src/voiceover-manifest.json` に `{ "<id>": { "duration": 秒, "hash": "" } }` を書きます。
- せりふが まえや つぎの せりふに かさなると、プレビュー・書き出しが エラーで とまります（`at` か シーンの ながさを なおしてください）。
- 話しているあいだは BGM が自動で小さくなります。

## 構成

```
src/
  KumonosuVideo.tsx     シーンをつなぐ本体 + ナレーション/BGM
  scenes/               シーン（S01〜S10）
  components/           くものす（Web.tsx）・くも・むし・にわ など（Things.tsx）、こども・文字・ラベル
  lib/                  アニメーション・タイミング計算・くものすの かたち（web.ts）
scripts/
  make_bgm.py           BGM 合成
  generate-voiceover.ts ナレーション生成
  stills.mjs            確認用の静止画書き出し
```
