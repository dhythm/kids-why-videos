# はなぢは どうして でるの？

「なんで はなぢが でるの？」と きいた こども（保育園児・3〜6さいくらい）に、はなぢの しくみ・でやすい とき・とめかたを つたえる、約2分27秒のモーショングラフィックス動画です。
文字はひらがなを少しだけにして、絵と動きで伝えます。

伝えたいことは、次の5つです。

- はなは くうきの トンネル。すった くうきを あたためて しめらせる ために、ほそい「ちの みち」（血管）が たくさん ある
- はなの いりぐちの ちかくは、ちの みちが とくに おおく、それを おおう かべが とても うすい。だから やぶれやすい
- でやすいのは、ほじった とき・つよく かんだ とき・ぶつけた とき・くうきが かわいている とき・かぜや かふんで はなが あれている とき
- はなぢは「なにかの ために」でるのでは なく、はなの なかの ちいさな けが。ちは じぶんで かたまって ふたを する
- とめかたは「すわって すこし したを むく → はなの やわらかい ところを つまむ → くちで いきを して 10ぷん くらい まつ」。うえは むかない。くちに きた ちは のまないで だす。とまったら そーっと

「はなぢは なんの ために あるの？」には、「ための ものでは ない（けが）」と 正直に こたえ、かわりに「はなに ちの みちが おおい わけ」と「ちが かたまる ちから」を つたえる つくりに しています。
こわがらせない ように、ちは しずくの 絵に とどめ、「ちいさな けが」「だいじょうぶ」「おとなに おしえてね」で しめています。

## シーン

1. はじまり — はなから ちが たらーり。これは はなぢ。どうして でるの？
2. はなの トンネル — はなは くうきの とおりみち。あたためて しめらせる。その ために ちの みちが たくさん
3. うすい かべ — いりぐちの ちかくは ちの みちが いっぱいで、かべが うすい（ひふと くらべる）。やぶれて ちが でる
4. どんな とき？ — ほじほじ・つよく かむ・ぶつける・カラカラ。かぜや かふんで むずむず する ときも
5. なんの ため？ — ための ものじゃ ない。ひざの すりきずと おなじ「ちいさな けが」。なおしやさんが ちの ふたを つくる
6. とめかた — すわって すこし したを むく。やわらかい ところを ぎゅっと つまむ。くちで いきを して じゅっぷん
7. うえは むかない — ちが のどに ながれて きもち わるく なる。くちに きた ちは ぺっ
8. とまった あと — かさぶたの ふた。さわったり つよく かむと とれちゃう。そーっと
9. ふりかえり — ちいさな けが → したを むいて ぎゅっ → だいじょうぶ。おとなに おしえてね。またね！

- 2D: SVG + React（Remotion）。ラベル・ことば・こどもの 部品と「なおしやさん」は `bansoko` から 流用
- はなぢの いきおい・ふたの できかた・とけいの はり・くうきの いろは `src/lib/nose.ts`（テスト つき）
- BGM: Python（numpy）で合成
- ナレーション: ElevenLabs `eleven_v4`（声: Sameno）。せりふごとに べつべつに 生成し、あたまと おしりの むおんを きって みじかく フェード
- サムネイルは、YouTube 用の 専用イラスト [thumbnail.jpg](thumbnail.jpg)（1280×720）と、Remotion の `Thumbnail`（SVG で えがいた もの）が あります

## 内容の根拠（おとな向け）

| 動画での 言いかた | 根拠・注意 |
| --- | --- |
| はなは くうきを あたためて しめらせる。その ために ちの みちが たくさん | 鼻腔の 粘膜は 血管が 豊富で、吸った 空気の 加温・加湿を する。「その ために ある」は こども向けの 言いかたで、血管には 粘膜に 栄養を はこぶ などの 役割も ある |
| いりぐちの ちかくは ちの みちが とくに いっぱいで、かべが うすい | 鼻中隔の 前方（キーゼルバッハ部位）は 細い 血管が あつまり、粘膜が うすい。こどもの 鼻出血の 大半は ここからの 前方出血。動画の 断面図は 模式図で、実際の 形や 縮尺とは ちがう |
| ほじった・つよく かんだ・ぶつけた・かわいた とき | こどもの 鼻出血で もっとも 多い きっかけは 鼻いじり（指に よる 外傷）。粘膜の 乾燥、外傷も 局所の 要因と して 挙げられている |
| かぜや かふんで むずむず する ときも | 鼻炎（感染・アレルギー）で 粘膜が あれたり、こする・かむ 回数が ふえると 出やすい |
| なにかの ために でるんじゃ ない。ちいさな けが | 鼻出血は 粘膜の 血管が やぶれた 出血で、からだの 役に 立つ はたらき では ない。「のぼせを さます」「わるい ちを だす」と いった 説に 根拠は ない |
| ちは じぶんで かたまって ふたを する | 止血（血小板が あつまり、フィブリンで かたまる）。「なおしやさん」は これを まとめた たとえ |
| すわって すこし したを むく・やわらかい ところを つまむ | 座って やや 前かがみに なり、骨の ない 小鼻を 親指と 人さし指で つまんで 圧迫する。鼻の つけね（骨の ところ）では ない |
| じゅっぷん くらい はなさないで まつ | 資料に より 約10分（世田谷区）、10〜15分（AboutKidsHealth など）と 幅が ある。途中で 何度も 離して 確かめない。動画の とけいは 10分を 指す |
| うえを むかない。のどに ながれて きもち わるく なる | 上を むく・ねかせると 血が のどへ ながれ、気分が 悪く なったり 吐いたり する。首の うしろを たたく のも 効果は ない |
| くちに きた ちは のまないで ぺっ | のみこむと 吐き気の もとに なる ため、口に きた 血は 出させる |
| とまったら さわらない・つよく かまない | 止血直後は かさぶた（血餅）が とれると 再出血する。しばらくは 鼻を いじらず、強く かまない |

### 動画に 入れなかった こと

- ティッシュや 綿を 鼻の おくに つめるのは、すすめない 資料が 多い（繊維が のこる、ぬく ときに かさぶたが とれる）。動画では ふれていません。
- つまんでも 止まらない ときに 鼻の うえを 冷やす、と いう 案内も ありますが、はぶきました。
- 「チョコレートを 食べると 鼻血が でる」「こうふんすると でる」は 根拠が はっきり しない ため、入れていません。

### おうちでの 注意

- 10分 つまんでも 止まらない ときは もう 1回。それでも 止まらない、30分 以上 つづく、口から あふれるほど 出る、顔や 頭を 強く ぶつけた あと、顔色が 悪い・ふらふら する ときは 受診して ください。
- なんども くりかえす、あざが できやすい・歯ぐきからも 血が 出る、2さい 未満の 鼻血は、耳鼻咽喉科や 小児科に 相談して ください。
- つめを みじかく する、部屋を 加湿する、鼻炎を 治療する と、くりかえしを へらせると されています。

## 必要なもの

- Node.js 22 以上
- Python 3 + numpy
- ffmpeg

## 使いかた

```bash
npm i
npm run bgm      # BGM を生成（プレビューの前に 1 回）
npm run dev      # Remotion Studio でプレビュー
npm run render   # BGM を生成して out/hanaji.mp4 に書き出し
npm test         # タイミング計算・はなぢの しくみの テスト
npx remotion still src/index.ts Thumbnail out/thumbnail.png   # サムネイルの書き出し
```

python3 に numpy が ないときは `uv run --no-project --with numpy python scripts/make_bgm.py public/bgm.wav` でも作れます。

## ナレーション

台本 `src/narration.json` に、せりふごとの「シーン番号（0はじまり）」と「シーン内で話しはじめるフレーム（at）」が入っています。
シーンの ながさは `src/lib/durations.ts` に まとめてあります。
音声 `public/voiceover/*.mp3` はリポジトリに含めています（TTS は作るたびに少し変わるため）。

- 台本を変えたら `.env`（この フォルダ か リポジトリの ルート）に `ELEVENLABS_API_KEY=...` を書いて `npm run voiceover`。変わったセリフだけを作り直し、`src/voiceover-manifest.json` に長さを記録します。
- ひらがなの「はな」は、「花」の アクセントに なったり、「は」が 助詞の ように きこえて 消えたり します。よみまちがう せりふには、`tts` に 漢字まじりの 文（「鼻」「鼻血」「血」など）を 入れると、そちらが 読みあげられます（`text` は 台本の まま）。
- この 動画の 音声は、whisper での 聞きとり 確認を まだ していません（耳で 聞いて たしかめて ください）。
- せりふが まえや つぎの せりふに かさなると、プレビュー・書き出しが エラーで とまります。シーンの きりかえに かかる せりふは `npm test` で みつかります。
- 話しているあいだは BGM が自動で小さくなります。
