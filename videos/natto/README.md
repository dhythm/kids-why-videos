# なっとうは どうして ネバネバ なの？

「なっとうって どうして ネバネバ しているの？」という、こども（4〜6さいくらい）の ぎもんに こたえる、約2分40秒のモーショングラフィックス動画です。
文字はひらがなを少しだけにして、絵と動きで伝えます。

伝えたいことは、次の4つです。

- なっとうの もとは だいず。にた だいずは ネバネバ しない
- だいずに すみついた なっとうきんが、だいずを たべて ふえ、ネバネバを つくる（むかしは いねの わらに すむ なっとうきんで つくった）
- ネバネバの しょうたいは、うまみの もと（グルタミンさん）が ながく つながった くさり。からまって のびる いとに なる
- なっとうきんが ネバネバを つくるのは じぶんを まもるため、と かんがえられているが、まだ しらべている ところ。まぜると くうきが はいって ふわふわに なる

## シーン

1. はじまり — なっとうを ぐるぐる → のびーる！ どうして ネバネバ？
2. だいず — なっとうの もとは だいず。にた だいずは つるん、なっとうは ネバー。だれが？
3. なっとうきん — まめを おおきく すると なっとうきん。むかしは いねの わら（わらづと）
4. つくりかた — みずに つける → むす → なっとうきんを ぱらぱら → あったかい へやで いちにち くらい
5. もぐもぐ — なっとうきんが だいずを たべて ふえ、ネバネバを つくりだす
6. しょうたい — うまみの もとが てを つないだ ながーい くさり。からまって のびる
7. なんの ため？ — かわいたり ごはんが なくなったり したとき じぶんを まもる、と かんがえられている。はかせも しらべちゅう
8. まぜまぜ — くさりが のびて くうきが はいり、ふわふわ。いとも いっぱい
9. ふりかえり — だいず ＋ なっとうきん → くさり → ネバネバ。またね！

- 2D: SVG + React（Remotion）。こども・ラベル・ことばの 部品は `yogurt` から 流用
- ネバネバの いとの たるみ・ふとさ、くさりの ならびは `src/lib/strings.ts`（テスト つき）
- BGM: Python（numpy）で合成
- ナレーション: ElevenLabs `eleven_v4`（声: Sameno）。せりふごとに べつべつに 生成し、あたまと おしりの むおんを きって みじかく フェード
- サムネイル: `thumbnail.png` / `thumbnail.jpg`（1280×720。画像生成で 作成。プロンプトは `thumbnail_prompt.txt`）。Remotion の `Thumbnail` コンポジションは 参照用

## 内容の根拠（おとな向け）

| 動画での 言いかた | 根拠・注意 |
| --- | --- |
| なっとうきんが だいずを たべて ネバネバを つくる | 糸引き納豆は、蒸煮大豆に 納豆菌（*Bacillus subtilis* var. *natto*）を 接種し、約40℃ 前後で 十数時間〜1日ほど 発酵させて つくる。ネバネバは 菌が 菌体外に 分泌する もの |
| ネバネバの しょうたいは うまみの もとの くさり | 糸の 主成分は γ-ポリグルタミン酸（γ-PGA）。グルタミン酸が γ位で 多数（数千〜）つながった 高分子で、ほかに フラクタン（レバン）なども ふくむ。グルタミン酸は うまみ成分だが、くさりに なった γ-PGA 自体が うまみを もつ わけではないので、動画では「うまみの もとの なかまが つながった」と 言うに とどめた |
| からまって のびる いとに なる | ながい 高分子が 水を ふくんで からみあい、ひっぱると のびる（曳糸性）。 |
| むかしは いねの わらで つくった | 稲わらには 枯草菌の なかまが すみ、芽胞は 熱に つよい。わらづとを 煮沸すると ほかの 菌が へり、納豆菌が のこって 発酵が すすむ。いまは 純粋培養した 菌を つかう |
| じぶんを まもるため、と かんがえられている | 枯草菌の γ-PGA は、乾燥などの 環境ストレスからの 保護、栄養が ないときの 貯蔵、金属イオンの 隔離などの 役割が 提案されている。はっきり 決まって いないため「かんがえられている」「しらべている」と した |
| まぜると くうきが はいって ふわふわ | かきまぜると 糸が のび、気泡を ふくんで 白っぽく ふわっと する。回数と 味の 関係には 諸説 あるので、動画では 回数や おいしさには ふれていない |

### たべさせる ときの 注意

- 大豆は 特定原材料に 準ずる アレルゲン（推奨表示 品目）です。はじめて たべる ときは 少量から。
- 小さい こどもには、ひきわり や きざんだ なっとうが のどに つまりにくく おすすめです。
- 納豆に ふくまれる ビタミン K は ワルファリン（抗凝固薬）の 効果を よわめます。服用中の 家族が いる 場合は 医師の 指示に したがって ください。

## 必要なもの

- Node.js 22 以上
- Python 3 + numpy
- ffmpeg

## 使いかた

```bash
npm i
npm run bgm      # BGM を生成（プレビューの前に 1 回）
npm run dev      # Remotion Studio でプレビュー
npm run render   # BGM を生成して out/natto.mp4 に書き出し
npm test         # タイミング計算・いとの かたちの テスト
npx remotion still src/index.ts Thumbnail out/thumbnail-ref.png   # サムネイルの参照画像
```

python3 に numpy が ないときは `uv run --no-project --with numpy python scripts/make_bgm.py public/bgm.wav` でも作れます。

## ナレーション

台本 `src/narration.json` に、せりふごとの「シーン番号（0はじまり）」と「シーン内で話しはじめるフレーム（at）」が入っています。
シーンの ながさは `src/lib/durations.ts` に まとめてあります。
音声 `public/voiceover/*.mp3` はリポジトリに含めています（TTS は作るたびに少し変わるため）。

- 台本を変えたら `.env`（この フォルダ か リポジトリの ルート）に `ELEVENLABS_API_KEY=...` を書いて `npm run voiceover`。変わったセリフだけを作り直し、`src/voiceover-manifest.json` に長さを記録します。
- 全せりふを whisper（mlx-whisper large-v3-turbo）で 聞きとり、台本どおりに 読まれていることを たしかめています（s03_a の「ぐーんと」は「グーッと」とも きこえます）。
- せりふが まえや つぎの せりふに かさなると、プレビュー・書き出しが エラーで とまります。シーンの きりかえに かかる せりふは `npm test` で みつかります。
- 話しているあいだは BGM が自動で小さくなります。

## 構成

```
src/
  NattoVideo.tsx        シーンをつなぐ本体 + ナレーション/BGM
  Thumbnail.tsx         サムネイル
  scenes/               シーン（S01〜S09）
  components/           なっとう・はち・おはし・なっとうきん・わらづと・くさり など（Natto.tsx）、こども・文字・はいけい
  lib/                  アニメーション・タイミング計算（cues.ts / timeline.ts）・いとの かたち（strings.ts）・いろ（color.ts）・シーンの ながさ
scripts/
  make_bgm.py           BGM 合成
  generate-voiceover.ts ナレーション生成
  stills.mjs            確認用の静止画書き出し
```
