# あそぶ じかんは どこに いったの？

あさの したくや よるの ごはん・はみがきに じかんが かかって、「もっと あそびたい！ やだやだ！」と なる こども（保育園児・3〜6さいくらい）に、
「さきに したくを おわらせると、たのしい じかんが たくさん のこる」ことを つたえる、約2分20秒のモーショングラフィックス動画です。
文字はひらがなを少しだけにして、絵と動きで伝えます。

伝えたいことは、次の4つです。

- とけいは とまらない。ほいくえんに いく じかん・ねる じかんは うごかせない（じかんは のびない）
- あさ（よる）の じかんは「ブロック むっつ」。したくが つかった のこりが、あそぶ じかん
- さっと おわると みっつ のこる。よそみ・ごろごろ すると ひとつ だけ。「やだやだ」と ないて いる あいだも ブロックは へる
- だから「したくの ときは したく だけ」。おもちゃには「あとでね」。のこった じかんは ぜんぶ じぶんの もの

こどもを せめる 言いかた（「わがまま」「だらだら」「だめ」）は つかわず、かなしい きもちは うけとめた うえで（「かなしいね」）、
「じかんの しくみ」と「できる こと」を しめす つくりに しています。

## シーン

1. はじまり — もっと あそびたいのに、もう いく じかん。やだやだ！ あそぶ じかんは どこに いったの？
2. とけいは とまらない — 「まって」と いっても とけいは すすむ。いく じかんは うごかせない
3. じかんの ブロック — あさの じかんは ブロック むっつ。シャワー・きがえ・ごはんが つかい、のこりが あそぶ じかん
4. さっと おわると — ざーっ・ぱぱっ・もぐもぐ。みっつ のこって たくさん あそべる
5. ごろごろ・よそみ — したくが ブロックを どんどん つかって、あそぶ ブロックは ひとつ だけ
6. やだやだ — ないて いる あいだも とけいは すすみ、さいごの ひとつも なくなる。かなしいね。でも じかんは もどらない
7. よるも おなじ — ねる じかんは きまっている。ごはん・きがえ・はみがきが さっと おわると、えほんや あそびの じかんが のこる
8. どう したら いい？ — したくの ときは したく だけ。おもちゃには「あとでね、まっててね」。のこりは ぜんぶ きみの もの
9. ふりかえり — とけいは とまらない → さきに したく → たのしい じかん。あしたは いくつ のこせるかな？ またね！

- 2D: SVG + React（Remotion）。こども・ラベル・ことばの 部品は `bansoko` から 流用
- じかんの ブロックの けいさんは `src/lib/blocks.ts`（テスト つき）
- BGM: Python（numpy）で合成
- ナレーション: ElevenLabs `eleven_v4`（声: Sameno）。せりふごとに べつべつに 生成し、あたまと おしりの むおんを きって みじかく フェード
- YouTube サムネイルは専用イラストの [`thumbnail.jpg`](thumbnail.jpg)（1280×720）。生成プロンプトは [`thumbnail_prompt.txt`](thumbnail_prompt.txt) にあります。

## おうちでの つかいかた（おとな向け）

以下は 作者の かんがえと、一般に いわれている 子育ての くふうに もとづく もので、**この 動画の ために 文献を 確認した ものでは ありません**。

- 3〜6さいの こどもは「あと 10ぷん」の ような 時間の ながさを まだ うまく つかめない と いわれます。だから 動画では 時計の よみかた ではなく、「かぞえられる ブロック」に おきかえました。
- 動画の「ブロック むっつ」は たとえ です。おうちでは、タイマーや すなどけい、つみき・マグネットを ならべて「したくが おわったら のこりは あそぶ じかん」と 目で みえる ように すると、動画と つなげやすいと おもいます。
- 「はやく しないと あそべないよ」（おどし）より、「さきに したくを すると、あそぶ じかんが のこるよ」（しくみの せつめい）の ほうが、動画の 言いかたと そろいます。
- ないて いる ときは、まず きもちを うけとめる（「もっと あそびたかったね」）。「だから いったでしょ」は 動画でも いって いません。じかんの はなしは、おちついてから・つぎの あさの まえに。
- したくに じかんが かかる のは、やりかたが まだ むずかしい・ねむい・おなかが すいていない など、こども だけの せいでは ない ことも あります。したくの りょうや おきる じかんを みなおす のも 手です。

## 必要なもの

- Node.js 22 以上
- Python 3 + numpy
- ffmpeg

## 使いかた

```bash
npm i
npm run bgm      # BGM を生成（プレビューの前に 1 回）
npm run dev      # Remotion Studio でプレビュー
npm run render   # BGM を生成して out/jikan.mp4 に書き出し
npm test         # タイミング計算・じかんの ブロックの テスト
npx remotion still src/index.ts Thumbnail out/thumbnail.png   # Remotion の参照画像を書き出し
```

python3 に numpy が ないときは `uv run --no-project --with numpy python scripts/make_bgm.py public/bgm.wav` でも作れます。

## ナレーション

台本 `src/narration.json` に、せりふごとの「シーン番号（0はじまり）」と「シーン内で話しはじめるフレーム（at）」が入っています。
シーンの ながさは `src/lib/durations.ts` に まとめてあります。
音声 `public/voiceover/*.mp3` はリポジトリに含めています（TTS は作るたびに少し変わるため）。

- 台本を変えたら `.env`（この フォルダ か リポジトリの ルート）に `ELEVENLABS_API_KEY=...` を書いて `npm run voiceover`。変わったセリフだけを作り直し、`src/voiceover-manifest.json` に長さを記録します。
- 全せりふを whisper（mlx-whisper large-v3-turbo）で 聞きとり、台本どおりに 読まれていることを たしかめています（`s04_b` の「みっつも」だけ「3つの」と 聞きとられました）。
- せりふが まえや つぎの せりふに かさなると、プレビュー・書き出しが エラーで とまります。シーンの きりかえに かかる せりふは `npm test` で みつかります。
- 話しているあいだは BGM が自動で小さくなります。

## 構成

```
src/
  JikanVideo.tsx        シーンをつなぐ本体 + ナレーション/BGM
  Thumbnail.tsx         サムネイル
  scenes/               シーン（S01〜S09）
  components/           じかんの ブロック・とけいさん・したくの どうぐ・おもちゃ など（Jikan.tsx）、こども・文字・はいけい
  lib/                  アニメーション・タイミング計算（cues.ts / timeline.ts）・じかんの ブロック（blocks.ts）・いろ（color.ts）・シーンの ながさ
scripts/
  make_bgm.py           BGM 合成
  generate-voiceover.ts ナレーション生成
  stills.mjs            確認用の静止画書き出し
```
